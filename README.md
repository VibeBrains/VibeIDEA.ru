# vibeidea.ru

Лендинг [VibeIDEA](https://github.com/VibeBrains/VibeIDEA) — статический сайт на Astro.
Цель страницы одна — скачивания: кнопки ведут прямо на сборки последнего релиза для macOS, Windows и Linux.
Русский — базовый язык по адресу `/`, английский — по адресу `/en/`.

## Характер

Сайт из одного семейства с [vibeide.ru](https://vibeide.ru) и [vibememory.ru](https://vibememory.ru).
Общие у них основной шрифт, сетка, правила текстов и анимаций, переключатель языка и гейт локализации.
Своё у VibeIDEA взято из её иконки «терминал + искра ИИ»:
- палитра — графитовая плитка `#16171B`, приглашение терминала от циана `#00E5FF` к фиолетовому `#9D5CFF`, искра `#FF2E97`
- заголовки набраны JetBrains Mono: IDE стоит на платформе JetBrains и говорит голосом терминала
- углы острые, линии тонкие, фон — точечная сетка, в заголовке мигает курсор
- плашки плотной строки героя — цвета искры
- 3D: окно в духе IntelliJ с деревом проекта и PHP-диффом, над ним вращается объёмная искра; кольцо языковых серверов
- сцены: предохранители (детектор петель останавливает ход), дизайн-детектор (луч и замеры), детектор нейрослопа

## Сборка

```bash
bun install
bun run dev       # разработка, http://localhost:4321
bun run build     # статическая сборка в dist/
bun run preview   # просмотр собранного dist/
bun run check     # типы (astro check), сборка и гейт локализации (bun test)
```

Внешний запрос у страницы один — к API релизов GitHub, чтобы показать сборки, вышедшие после выкладки.
Трекеров, аналитики и CDN нет.

## Что где

- `src/pages/` — две страницы: `index.astro` (ru) и `en/index.astro`
- `src/components/` — секции страницы, `Landing.astro` собирает их по порядку
- `src/locales/ru.json`, `en.json` — все строки интерфейса, плоские ключи с точками
- `src/config/` — ссылки, языки кольца, агенты, виды сборок для разбора релизов каркасом
- `src/config/build.ts` — релизы на момент сборки: ссылки на скачивание работают и без скриптов
- `src/scripts/main.ts` — подключение клиентских скриптов каркаса: появление, язык, живые релизы, 3D-наклон
- `src/styles/theme.css` — характер VibeIDEA поверх базовых стилей каркаса
- `tests/locales.test.ts` — гейт локализации каркаса со словарём данных сайта

## Каркас

Общее у сайтов семейства — в пакете [SiteKit](https://github.com/VibeBrains/SiteKit) (`@vibebrains/site-kit`):
языки и переводчик, гейт локализации, базовые стили, `Base`, `Header`, `Footer`, `Lines`, `FusedLine`, клиентские скрипты, выкладка.
Здесь — то, что делает сайт собой: секции, сцены, тексты, тема.
Пакет закреплён тегом в `package.json`; обновление — новый тег там и `bun install`.

## Ссылки на сборки

В репозитории VibeIDEA лежат и релизы апстрима (`pycharm/…`): сборки VibeIDEA — только теги `vX.Y.Z`.
Каждая кнопка ищет последнюю сборку своей платформы: `.dmg`, `.exe` (или `.win.zip`), `.tar.gz`.
Ссылки подставляются при сборке, а в браузере обновляются из API GitHub.
После выпуска VibeIDEA достаточно пересобрать и выложить сайт.

## Правила текстов

Одна строка каталога — одно предложение, в разметке строки выводятся отдельными блоками.
Точки в конце предложения нет, предложение не длиннее 160 символов.
Текст в разметке и в доступных именах — только из каталога.
Названия продуктов, языков и серверов — данные из `src/config/`, гейт знает их поимённо.
Факты о продукте берутся из README и `docs/vibe/functional.md` VibeIDEA, а не придумываются.

## Анимации

CSS и немного JS.
Зацикленные сцены играют, только пока видны на экране.
3D-наклон за курсором — только при мыши.
При `prefers-reduced-motion: reduce` анимаций нет: сцены показывают итоговое состояние.

## Выкладка

`./deploy.sh` (через `site-deploy` каркаса) собирает сайт и кладёт его на общий хост семейства в `/srv/vibeidea/site/<коммит>`.
Ссылка `current` переключается одним переименованием, три последние сборки остаются для отката.
Выкладывается только закоммиченное.
Хост тот же, что у VibeMemory и vibeide.ru, SSH-алиас `vibememory`.
Блок сайта — сниппет `familySite` в `infra/Caddyfile.tmpl` репозитория VibeMemory, ставит его `infra/caddyApply.sh`.
